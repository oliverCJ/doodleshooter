# Doodle District

[English](README.md)

一款画在横线笔记本纸上的第一人称涂鸦风生存射击游戏。你可以用钩爪穿梭在屋顶和峡谷之间，挥刀弹回敌人的子弹，投掷手雷，看看自己能撑过多少波敌人。可以单人游玩，也可以和朋友合作或对战。

画面内容都由代码生成，基于 three.js。项目没有模型、贴图或音频文件；纸张、墨线轮廓、排线阴影、敌人和音乐都是程序化生成的，包括每张地图对应的 8-bit 主题音乐，可以在设置中切换，也可以按 `M` 切换。

## 运行方式

推荐使用 Node 本地游戏服务：

```bash
npm install
npm run serve
```

Node 服务会同时提供游戏页面和本地 PeerJS 信令端点。启动后会打印类似 `http://192.168.1.23:8910` 的局域网地址。同一局域网内的其他玩家直接打开这个地址即可，不需要 clone 代码，也不需要各自启动服务。

在线对战页使用“局域网对战 / 公网对战”两个 Tab。公网联机开关位于公共区域，关闭后只禁用公网快速匹配、公网大厅创建、公网大厅加入和公网公开大厅刷新，不影响局域网对战。

局域网对战使用本地信令和浏览器 WebRTC P2P，可以在无公网环境下创建公开或私密大厅、快速匹配局域网公开大厅、刷新局域网公开大厅，也可以输入大厅代码加入指定大厅。公网开关开启时，局域网 P2P 会额外使用 STUN 辅助发现候选地址；关闭时只使用局域网本地候选，保持离线。

Docker 使用同一个 Node 局域网服务：

```bash
docker compose up --build
```

Docker 服务会暴露 `http://<宿主机局域网IP>:8910`，并提供离线局域网联机所需的 `/peerjs` 信令端点。

轻量静态备用服务：

```bash
python3 serve.py --lan 8910
```

Python 服务适合做静态页面测试和公网联机页面托管，但不提供离线局域网信令。离线局域网联机请使用 `npm run serve` 或 Docker 启动方式。

如果局域网设备无法打开页面，请确认所有设备在同一网络内，macOS 或系统防火墙允许 Node/Python 接收入站连接，并确认路由器没有开启 Wi-Fi 客户端隔离。

如果部署到 Vercel 或其他静态托管平台，可以直接部署整个目录，用于公网联机页面访问。

## 模式

- **单人生存**：抵御一波波敌人。每 5 波出现 Boss，并在第 5、10、15 波等节点解锁检查点。
- **训练场**：练习射击、移动靶、假人靶和抓钩路线，不生成普通生存敌人。
- **自由混战**：最多 10 名玩家，先达到 20 次击杀获胜；当第二名玩家加入后开始 10 分钟倒计时。大厅内任意玩家都可以开始。死亡镜头后按任意键即可复活，并获得 2 秒护盾；2 分半无输入会被踢出，但可以一键重连。脱战数秒后会自动回血，冲刺时不会回血，因此在线模式下敌人只掉落弹药。

多人模式基于 WebRTC（PeerJS）进行 P2P 通信，因此公网模式可以运行在静态托管环境中，不需要游戏服务器。在“在线对战”中可以快速匹配、创建公开或私密大厅、刷新公开大厅列表，或者输入好友提供的五位大厅代码加入。

局域网和公网使用独立的大厅发现逻辑。局域网公开大厅只会被访问同一个局域网游戏地址的玩家匹配到。玩家可以中途加入已经开始的比赛。房主浏览器负责保存比分，每名玩家本地运行自己的角色。

## 武器和装备

当前武器包括步枪、霰弹枪、狙击枪（带瞄准镜）、左轮手枪和太刀。主菜单提供 4 个武器槽位配置：一个主武器槽、一个近战武器槽，以及两个可选择枪械或近战武器的副武器槽。同一套配置中不能重复选择同一把武器，单人、训练场和在线对战都会使用同一套武器注册表和配置规则。

太刀按住格挡可以弹开部分来袭子弹并反射一部分伤害。太刀击杀会积累能量；能量亮起后，可以突进到被标记的敌人并处决它（仅单人模式）。

手雷会弹跳，然后产生一团橙色爆炸并灼烧纸面；按住投掷键可以蓄力扔得更远，并显示抛物线。钩爪消耗呼吸值：悬挂时消耗，落地后恢复；斩击可以切断他人的绳索。对战中，举起太刀可以招架斩击并偏转部分子弹，枪械使用独立的对战伤害表；狙击枪仍然可以一枪击杀。

## 地图

- **Doodle District**：街道、屋顶和消防梯构成的城区，高处有钩爪环。单人模式使用紧凑的原始街区；多人模式会扩展为更大的区域：外圈街道、墙体、无法钩住的肋状穹顶、中央开放场地、尺子桥、穹顶下悬挂平台，以及可以钩住并乘坐的慢速纸飞机。
- **Doodle Mexico**：阳光炙烤的墨西哥小镇。广场中有喷泉和巨大的悬浮宽檐帽，乐队亭里有三名不停演奏的 mariachi，教堂带钟楼和第二座圆顶塔，土坯房带屋顶楼梯，彩纸旗横跨广场，还有条纹市场摊位、悬挂皮纳塔、玉米饼车、仙人掌和周边台地。罐子、箱子、木桶、仙人掌和皮纳塔都可以被子弹、刀和爆炸破坏；皮纳塔会掉落玉米饼，作为该地图的回血道具。地图拥有自己的 mariachi 圆舞曲主题音乐。
- **Doodle Training Range**：固定训练场地图，包含靶道、静态靶、移动靶、假人靶、中央建筑和有支撑结构的抓钩平台。

单人模式可以在主菜单选择地图；联机时由房主在大厅中选择地图，所有玩家会从不同出生点开始。

## 敌人

敌人包括普通兵、冲锋兵、爆破兵、带可躲避激光的狙击手、飞行敌人、重装敌人和持盾敌人。Boss 每隔数波轮换出现，包括 The Doodler、The Eraser 和 The Inkblot，每个 Boss 都有自己的行动方式。

## 画面原理

场景会先渲染到包含阴影、墨水 id、视图空间法线和浮点深度的缓冲区。后处理会基于反深度拉普拉斯算子绘制轮廓，叠加贴合表面的排线、纸张颗粒、横线和红色页边线。抖动是静态的，因此画面不会闪烁。
